# OrgMaster

快速、直覺的組織架構圖畫布編輯器。節點可使用報告樹或組織層級排版，每個職位節點也能獨立設定下一階為橫向或縱向排列。

## 本機啟動

```powershell
npm install
npm run dev:local
```

固定本機網址：[http://localhost:5000](http://localhost:5000)

若從檔案總管或其他會自動回收終端視窗的啟動器開啟，請改用 `npm run dev:local:window`，或雙擊 `scripts\\dev-local.cmd`。它會另開一個 PowerShell 視窗持續執行；若服務因錯誤停止，視窗會保留錯誤訊息，不會一閃即逝。

組織架構會由 `localhost:5000` 的本機服務管理版本工作區：`data/orgmaster-workspace.v1.json` 保存現行版／草稿清單，`data/orgmaster-versions/<versionId>.json` 保存各版本的 V5 文件。首次啟動會由既有 V4／V3／V2 文件建立現行版並在讀取時升級；原始來源不會被覆寫或刪除。同一台電腦上的不同 Chrome 視窗會共用版本工作區，草稿自動保存並以版本修訂避免舊視窗覆蓋新內容。

## 核心操作

- 左側主資料列可分別開啟員工、職位、部門與層級清單；再次點擊目前按鈕或面板收合按鈕即可收起並釋放畫布寬度。
- 主資料清單共用一致的操作節奏：標題列固定提供「新增」，資料列點擊選取，並依資料類型提供指派、定位、編輯、刪除或排序等操作。
- 三份清單各自只呈現唯一主檔名稱；員工任職、職位指派／部門、部門員工／職位等關聯資料，點選後在右側細節層查看。
- 三份清單都有獨立搜尋；職位清單可定位畫布節點，部門清單保留階層縮排，完整關聯資訊不在主清單重複呈現。
- 員工以 `departmentId` 歸屬部門；職位以 `departmentId` 歸屬部門並引用角色定義；員工與職位透過帶有效期間的任職配置連接。
- 部門可設定上層部門；部門移動會阻擋自我或子部門循環。主管／直線匯報關係暫不建立。
- 員工清單可搜尋姓名或部門；點選員工後在細節層查看目前任職職位。
- 從員工清單拖到職位會新增指派；同一員工可重複拖到多個職位。
- 從職位上的員工拖到另一職位會移動該次指派，拖到畫布空白處或按姓名旁的移除按鈕會解除指派；員工仍保留在清單。
- 在職位卡按右鍵可開啟常用操作選單；「職位複製」會在同階下一格建立同名、相同下層排列的空白職位，不會複製員工或下屬。
- 清單資料列支援 `Enter`／`Space` 選取、`F2` 編輯、`Delete` 刪除、`ContextMenu`／`Shift+F10` 開啟操作選單，`Escape` 關閉選單；右鍵仍可使用。
- `Escape` 一次只關閉或取消最上層的選單、編輯控制項或側欄；編輯／草稿中第一次先退出或取消，下一次才關閉側欄。
- 點選職位後，在右側編輯職位、查看員工指派與設定下層排列方式；點選員工或部門則切換至對應唯一主檔細節。
- 「層級」清單可維護 L1…Ln 的名稱與順序；職位明細可逐一指定層級。上下級連線仍由上級職位決定，層級只控制 Y 軸層帶，因此基層職位即使直接向部門經理報告，也能排在組級主管下方。
- 所有使用中職位完成層級指派後，仍須明確切換為「層級排版」；可隨時切回「舊樹狀」，並獨立顯示或隱藏層級標籤與引導線。
- 層級排版以每層引導線作為同層職位卡片的共同起始基準；層級之間固定保留 20px 緊湊間距，並保留各分支的 X 軸位置，只有卡片水平範圍重疊時才向下避讓並固定保留 20px 間距。
- 頂端盾牌入口可設定具有兼任風險的職務組合、低／中／高風險等級、原因與啟用狀態；設定不包含負責人、期限、核准或處理流程。
- 頂端版本切換器可開啟「版本工作區」：從現行版或草稿建立具名草稿、切換／重新命名、封存／還原；現行版一般為唯讀，需明確進入「維護」模式才可直接修改。
- 版本工作區可勾選 2–5 個版本查看摘要，並進入兩版本唯讀比較畫面；差異清單支援部門、職位、組織層級、員工、任職、風險與版面篩選。比較不提供發布、合併或覆寫。
- 目前鉦富機械基準只保留 6 組重大職務不相容規則（高 4／中 2），不把一般主管跨職能、跨部門協調或執行者自檢直接列為風險。
- 同一員工的有效任職命中規則時，組織圖以橘色虛線或紅色雙層外框提示；不顯示風險文字，也不阻擋任職、組織調整或儲存。
- 下層橫向排列：父職位在上方，同一父職位的所有直接下屬共用一條由父卡片下緣延伸的水平幹線；個別職位升降階只改變末端垂直線長度，不改變共用起點。下層縱向排列：父職位維持在子樹上方，下一階由上至下排列並稍微右移，以垂直幹線向下接到各子卡片。
- `Tab` 新增子職位、`Enter` 新增同階。
- 拖曳卡片穩定命中明確放置區後，會磁吸到自動排版位置並更新穩定預覽；線條不跟隨游標連續重算，放開後才套用新的下屬關係或同階順序。
- 拖曳尚未命中穩定槽位時，卡片會跟隨游標移動，原位置保留藍框；穩定預覽成立後藍框消失並顯示完整新排版。
- 放置判斷採用「子階中央槽位」與「同階間隙插入槽位」，依下層橫向／縱向排列自動切換槽位軸向。
- `Space` / `F2` 編輯；組織圖職位不綁定 `Delete`，請從右鍵選單或右側屬性進入安全刪除；`Ctrl+Z` / `Ctrl+Y` 復原重做。
- `Alt+V` / `Alt+H` 切換下層橫排／縱排、`/` 搜尋、`Ctrl+0` 顯示完整組織圖。
